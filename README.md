## 👋 嗨！我是胖達！

想要把 Discord 伺服器經營得有聲有色，卻覺得設定一堆冷冰冰的指令很頭痛嗎？

我們拋棄了複雜難懂的設定檔，為你打造了一個**極簡、漂亮又好用的「專屬網頁控制台」**。無論你是要抓出搗蛋鬼、舉辦抽獎活動，還是設立專屬的客服中心，只要點點滑鼠就能輕鬆搞定！

## 🌟 胖達能幫你做什麼？

### 🛡️ 你的 24 小時貼身保鑣 (全域安全聯防)
有人來群組洗頻、貼詐騙連結或惡意爆破？胖達幫你自動擋下！
- **智慧防爆破**：短時間湧入大量假帳號？系統自動鎖定頻道，保護你的心血！
- **自動警告與禁言**：設定好底線，當有人違規次數達標，胖達會直接請他閉嘴。
- **乾淨俐落的日誌**：所有人的違規紀錄、進出紀錄，都在網頁後台一目了然。

### 🎫 專業級的私密客服中心 (Ticketing)
不想再把客服訊息混在公開頻道裡？
- **一鍵發布客服面板**：在網頁上打好字、選好顏色，按鈕面板直接發送到你的頻道。
- **專屬私密對話框**：有人點擊按鈕，胖達會立刻開一個只有你和他看得到的專屬頻道。
- **事後評分與紀錄留存**：問題解決後，自動寄送對話紀錄，還能讓用戶給客服打星星評分 ⭐！

### 🎮 讓群組嗨起來的娛樂經濟系統
社群死氣沉沉？讓大家每天都有上線的動力！
- **每日簽到與盲盒抽獎**：每天領金幣、買盲盒，看看誰才是真正的歐皇！
- **專屬電子寵物**：在 Discord 裡養一隻會餓、會升級的小跟班。
- **全域社群風雲榜**：跨伺服器的超熱血排行，誰才是全宇宙最富有的胖達用戶？

### 🧩 靈活的社群小工具
- **自動身分組面板**：男生、女生、喜歡打遊戲？讓用戶自己點按鈕領取身分組！
- **關鍵字自動回覆**：有人問「怎麼匯款」？胖達馬上幫你貼出預設好的解答。
- **動態語音包廂**：想要一個私密的聊天空間？自己開房、自己鎖門、還能踢人！
